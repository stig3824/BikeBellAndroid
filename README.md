# BikeBell Android

An Android port of the iOS BikeBell app that simulates a bike bell using the device's accelerometer.

## Features
- Motion-activated bell sounds
- Multiple bell types (Bike Bell and Cow Bell)
- Adjustable sensitivity and threshold
- Natural sound variations for realistic bell simulation
- Support for multiple simultaneous rings

## Requirements
- Android SDK 24 or higher
- Device with accelerometer sensor

## Building
1. Open the project in Android Studio
2. Sync project with Gradle files
3. Build and run on your device or emulator

## Usage
1. Launch the app
2. Press the center button to start motion detection
3. Shake your device to ring the bell
4. Access settings via the gear icon to adjust:
   - Motion threshold
   - Sound intensity
   - Bell type
